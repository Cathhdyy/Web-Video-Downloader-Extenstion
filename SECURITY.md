---

## Reporting a Vulnerability

The security of MediaGrabber PRO and the privacy of our users are of utmost importance.

If you believe you have discovered a security vulnerability in this extension, please follow these steps:

1. **Do NOT disclose the issue publicly** in GitHub issues, forums, or social media.
2. **Report Privately**: Please submit a private security advisory through GitHub via [Security Advisories](https://github.com/Cathhdyy/Web-Video-Downloader-Extenstion/security/advisories) or contact the project maintainers directly.
3. Include detailed steps to reproduce the vulnerability, including:
   - Proof of concept code or URL
   - Affected browsers and versions
   - Potential impact of the issue

We appreciate your effort in responsibly disclosing vulnerabilities and will respond promptly to acknowledge and resolve the issue.
